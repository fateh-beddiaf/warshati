# Security policy

## Reporting a vulnerability

Please **do not open a public issue** for a security problem.

Report it privately through GitHub: on the repository page open **Security → Advisories → Report a vulnerability**
([direct link](https://github.com/fateh-beddiaf/warshati/security/advisories/new)). Describe what you found, how to
reproduce it, and the Warshati version (shown in Windows under _Settings → Apps → Installed apps_).

You will get an answer as soon as possible. Once a fix is released, the advisory is published with credit to you if
you wish.

## الإبلاغ عن ثغرة أمنية

من فضلك **لا تفتح Issue عاماً** لمشكلة أمنية. أبلغ عنها بشكل خاص عبر GitHub: من صفحة المستودع افتح
**Security ← Advisories ← Report a vulnerability**
([رابط مباشر](https://github.com/fateh-beddiaf/warshati/security/advisories/new))، واذكر ما وجدته وكيف يمكن تكراره
وإصدار ورشتي.

## Supported versions

Only the latest release receives security fixes.
